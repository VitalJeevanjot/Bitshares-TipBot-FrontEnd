# BitShares Tip Bot front end

A 2019 Vue and Quasar web app for [BitsharesBot](https://github.com/VitalJeevanjot/BitsharesBot), a Discord bot for tipping on the BitShares blockchain. It connects to the user's wallet through [Beet](https://github.com/bitshares/beet), the BitShares companion app.

## Run it

1. Install the [Quasar CLI](https://v1.quasar-framework.org/start/quasar-cli).
2. Clone this repository and run `yarn` in the project folder.
3. Run `quasar dev`.

## Status

Archived 2019 project. It is not maintained, and its dependencies are years out of date.
